# لوحة إدارة مدرستي

واجهة إدارة عربية RTL مرتبطة بـ Cloudflare Worker وD1.

## الملفات
- `index.html`: صفحات لوحة الإدارة.
- `styles.css`: التنسيق.
- `app.js`: تسجيل دخول الإدارة، إدارة الأساتذة والأفواج والتلاميذ والإشعارات، وعرض فضاء الأستاذ المختار.

## الوظائف المرتبطة
- إضافة أستاذ مع حساب مستقل ومعرّف وكلمة مرور.
- اختيار أي أستاذ من قائمة «فضاء الأستاذ» لعرض أفواجه وتلاميذه ومدفوعاته.
- إضافة فوج وربطه بمعرّف الأستاذ المختار.
- عرض ملخص إيرادات المنصة وإيرادات الأستاذ المختار.
- مراجعة طلبات تسجيل التلاميذ الجديدة والموافقة عليها أو رفضها؛ لا يظهر التلميذ ضمن القائمة النشطة قبل الموافقة.
- نشر إشعار لجميع التلاميذ أو لتلميذ محدد، مع سجل للإشعارات المنشورة.

## النشر
انشر محتويات هذا المجلد على Cloudflare Pages. تأكد من أن عنوان الموقع موجود ضمن `ALLOWED_ORIGINS` في Worker، ثم انشر Worker بعد تحديث الكود.

## ملاحظات الإشعارات
الإشعارات الحالية تُحفظ في D1 وتظهر داخل مركز الإشعارات في حساب التلميذ. أثناء بقاء صفحة التلميذ مفتوحة، يتم التحقق من الإشعارات الجديدة كل دقيقة. إذا كان إذن إشعارات المتصفح ممنوحاً وكانت الصفحة في الخلفية، يمكن عرض تنبيه محلي.
يدعم السيرفر Web Push عند إعداد `VAPID_PRIVATE_JWK` و`VAPID_PUBLIC_KEY` واشتراكات المتصفح وCron Trigger.

## ملاحظات الأمان
- لا تضع `ADMIN_PASSWORD` أو كلمات مرور الأساتذة أو أسرار Worker داخل ملفات الواجهة.
- استخدم كلمات مرور قوية وفريدة، ولا تشاركها في المحادثات أو المستودعات العامة.
