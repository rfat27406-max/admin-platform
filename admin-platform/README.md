# لوحة إدارة مدرستي

واجهة إدارة عربية RTL مرتبطة بـ Cloudflare Worker وD1.

## التحديثات
- جميع الجداول والإحصائيات تُحمّل من قاعدة البيانات؛ أزيلت السجلات والأرقام التجريبية الثابتة.
- جلسة الإدارة تحفظ رمز الدخول في تخزين المتصفح المحلي، لذلك لا يُطلب الرمز في كل زيارة ما دامت الجلسة صالحة. لا تُحفظ كلمة المرور نفسها.
- فتح فضاء الأستاذ يتطلب اختيار الأستاذ وإدخال كلمة مروره الخاصة.
- إنشاء فوج يتطلب إدخال كلمة مرور الأستاذ المرتبط به، ويتحقق Worker من صحتها قبل حفظ علاقة الفوج بالأستاذ.
- مراجعة طلبات التسجيل وتفعيل الحسابات أو رفضها.

## النشر
انشر محتويات هذا المجلد على Cloudflare Pages. تأكد من وجود عنوان الموقع ضمن `ALLOWED_ORIGINS` في Worker، وانشر Worker المحدّث من مجلد `school-server`.

## الأمان
لا تضع `ADMIN_PASSWORD` أو كلمات مرور الأساتذة أو أسرار Worker داخل ملفات الواجهة أو المستودع. تخزن الواجهة رمز جلسة الإدارة فقط في `localStorage`؛ ويمكن إنهاء الجلسة بمسح بيانات الموقع من المتصفح.
