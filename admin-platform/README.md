# لوحة إدارة مدرستي

واجهة إدارة عربية RTL مرتبطة بـ Cloudflare Worker وD1.

## الوظائف
- لوحة إحصائيات من قاعدة البيانات الفعلية.
- مراجعة طلبات التسجيل والموافقة أو الرفض.
- إدارة الأساتذة: إضافة، تعديل البيانات، تغيير كلمة المرور، إيقاف الحساب أو إعادة تفعيله.
- إدارة الأفواج: إضافة، تعديل الاسم واليوم والتوقيت والسعر، إيقاف الفوج أو إعادة تفعيله.
- عرض قائمة التلاميذ مع البحث بالاسم.
- عرض سجل الحجوزات والمدفوعات وحالاتها.
- نشر الإشعارات العامة أو الموجهة إلى تلميذ محدد.
- فتح فضاء الأستاذ بعد إدخال كلمة مروره الخاصة.

## النشر
انشر محتويات هذا المجلد على Cloudflare Pages. تأكد من وجود عنوان الموقع ضمن `ALLOWED_ORIGINS` في Worker، وانشر Worker المحدّث من مجلد `school-server`.

## الأمان
لا تضع `ADMIN_PASSWORD` أو كلمات مرور الأساتذة أو أسرار Worker داخل ملفات الواجهة أو المستودع. تخزن الواجهة رمز جلسة الإدارة فقط، ويُبطل الخادم الرمز عند تسجيل الخروج. لا تحذف سجلات الحجوزات عند إيقاف فوج أو أستاذ.
