# admin-platform — لوحة إدارة مدرستي

واجهة إدارة عربية RTL متجاوبة، مستقلة عن واجهة التلميذ وعن مشروع السيرفر.

## محتويات المشروع
- `index.html` — هيكل الصفحات.
- `styles.css` — التصميم والتجاوب مع الهاتف والكمبيوتر.
- `app.js` — التنقل بين أقسام اللوحة والتنبيهات التوضيحية.

## تشغيل محلي
افتح `index.html` في المتصفح، أو استخدم إضافة Live Server في VS Code.

## النشر على Cloudflare Pages
1. ارفع هذه الملفات إلى مستودع GitHub `admin-platform`.
2. في Cloudflare Pages أنشئ مشروعاً جديداً واربطه بالمستودع.
3. اختر Framework preset: `None`.
4. اجعل Build command فارغاً.
5. اجعل Build output directory: `/` أو `.` حسب شاشة الإعداد.
6. انشر المشروع.

## مهم جداً — حالة النسخة
هذه النسخة واجهة أمامية أولية (UI prototype) ببيانات تعريفية/توضيحية. لا تحتوي على:
- تسجيل دخول إداري أو صلاحيات.
- اتصال فعلي بقاعدة بيانات D1 أو Worker.
- عمليات إنشاء/تعديل/حذف فعلية.
- تأكيد المدفوعات أو حساب دخل حقيقي.
- إرسال إشعارات أو جدولة تذكيرات.

الأزرار التي لم تُربط بعد تعرض رسالة توضيحية فقط. لا تستخدم هذه الواجهة لإدارة بيانات حقيقية قبل تنفيذ المصادقة الإدارية وحماية كل مسارات API على السيرفر.
